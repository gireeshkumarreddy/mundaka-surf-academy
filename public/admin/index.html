Editar la web

Desde aquí cambias precios, instructores, galería, opiniones, datos de contacto y textos. Cada vez que guardas se crea un cambio (commit) en GitHub y la web se publica sola en 1–2 minutos.

El token se guarda solo en este navegador. Puedes borrarlo cuando quieras con «Olvidar token».

«Ver sin conectar» abre una vista previa de solo lectura con los datos publicados en la web.

Cómo crear el token (una sola vez)
  1. En GitHub, abre Settings → Developer settings → Personal access tokens → Fine-grained tokens y pulsa Generate new token.
  2. Ponle un nombre (por ejemplo «Panel web») y una fecha de caducidad.
  3. En Repository access elige Only select repositories y marca solo el repositorio de la web.
  4. En Repository permissions busca Contents y elige Read and write. No hace falta ningún otro permiso.
  5. Pulsa Generate token, copia el código (empieza por github_pat_) y pégalo arriba.
